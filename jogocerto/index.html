🧭 Como usar esta aba

1. Configure o consumo dos veículos. 2. Escolha o veículo em cada jogo. 3. Registre cada abastecimento com seu próprio preço por litro. 4. Adicione manutenção e outros gastos que devem reduzir o lucro.

⛽ 1. Parâmetros de combustível

Configure uma vez; o sistema usa esses números para estimar o custo de cada jogo.

O preço por litro será informado em cada abastecimento. Para estimar o custo dos jogos, o sistema usa o preço do abastecimento mais recente registrado.

🚘 2. Veículo usado em cada jogo

Escolha qual veículo você usou em cada partida.

A lista de jogos fica recolhida para não deixar a tela muito comprida.

🛢️ 3. Registro de abastecimentos

Registre os abastecimentos e configure o consumo. O custo estimado da gasolina de cada jogo será descontado do lucro.
