## Contexto e créditos

Este repositório apresenta projetos e propostas de portfólio. A apresentação não significa aprovação, contratação ou vínculo com as empresas citadas. Marcas, fotografias, vídeos e conteúdo das empresas pertencem aos respectivos titulares e não recebem uma licença de redistribuição por este repositório. Parte das ilustrações da Bilatti foi gerada com IA.

As demonstrações preservam botões que abrem canais reais de contato. Não envie mensagens de teste. Instagram e outros recursos externos dependem de seus provedores. A demonstração da Luciana é uma cópia de portfólio; o endereço de produção permanece separado.

Links internos ajustados para subpastas do GitHub Pages. Configurações específicas do Netlify e arquivos de verificação de propriedade foram excluídos desta cópia.

## JogoCerto

Aplicativo independente em HTML, CSS e JavaScript, com foto incorporada. Os lançamentos são armazenados no localStorage do navegador de cada visitante. Não há sincronização entre dispositivos. A exportação e a importação de backup são feitas em JSON. A publicação contém o aplicativo, sem lançamentos pessoais pré-carregados.
